# 😎 Ibrar Saves The Day!

> *"He ran, but the biryani ran faster."*

A chaotic, hilarious browser-based arcade game where **Ibrar** — everyone's favourite hero — must dash around saving innocent people while being hunted by **sentient, homing food enemies**. Yes, the pizza is out for blood. The curry has a vendetta. The burger does not forgive.

---

## 🎮 Gameplay

- **Move** Ibrar around the arena using WASD, Arrow Keys, or the on-screen D-Pad
- **Save people** by touching them — each rescue scores you **+10 points**
- **Dodge all food** — it actively homes in on you, and it gets faster the better you do
- You have **3 lives** — lose them all and the food wins
- Difficulty **scales with your score**, so no round ever feels the same

---

## 🕹️ Controls

| Action | Input |
|--------|-------|
| Move | `WASD` / Arrow Keys / D-Pad |
| Save a person | Walk into them |
| Dodge enemies | Just... try |

> Works on **desktop and mobile** — touch D-pad included.

## 🚀 Getting Started

No build step. No npm install. Just open the file.

```bash

git clone https://github.com/your-username/ibrar-saves-the-day.git

# Open in your browser
open ibrar_saves_the_day_game.html
```

Or just drag the `.html` file into any browser and start saving lives immediately.

## 🏆 Scoring

| Action | Points |
|--------|--------|

Difficulty increases every 80 points — more food, faster homing, pure chaos.
